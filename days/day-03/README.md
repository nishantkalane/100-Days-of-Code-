# Day 3: Control Flow

## Topic learned

Conditional statements, comparisons, Boolean logic, modulo, nesting, and multiple decision branches.

## Why it matters

Control flow lets a program choose what to do based on the situation instead of following exactly one fixed path.

## Small example

```python
number = 8
if number % 2 == 0:
    print("even")
else:
    print("odd")
```
