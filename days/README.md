# Daily Work

Each `day-XX` folder is a self-contained record of one day of learning and practice.

## What belongs in a day folder

- `README.md`: the topic learned, the day's goal, and a short summary.
- `project/`: the original project for that day, with its own README and entry point.
- Existing exercise folders: earlier practice code that belongs to that day.

Broader explanations, terminology, examples, and reflection belong in the matching file under [notes](../notes). Follow the complete [daily workflow](../DAILY_CHECKLIST.md) when adding a new day.

For Days 1-15, the repository keeps the exercises and projects already written. From Day 16 onward, create one original project per day.
