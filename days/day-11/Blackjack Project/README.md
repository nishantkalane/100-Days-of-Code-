# Blackjack

## What it does

Runs a command-line Blackjack game with cards, player turns, dealer behavior, scoring, and win or loss conditions.

## Concepts practiced

- Lists and dictionaries
- Functions and shared game rules
- Random card selection
- Managing state across turns

## Run

```text
python main.py
```
