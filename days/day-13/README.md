# Day 13: Debugging

## Topic learned

Describing a problem, reproducing bugs, reading errors, using print statements, and using a debugger.

## Why it matters

Debugging is the process of understanding incorrect behavior instead of changing code randomly.

## Small example

```python
value = 10
print(f"value before calculation: {value}")
result = value / 2
print(f"result after calculation: {result}")
```

## Question to revisit

What is the smallest example that still reproduces a bug?

## Practice project

Day 13 contains debugging exercises rather than one new application. The work covers describing, reproducing, inspecting, and fixing behavior.

- **Inputs:** failing examples and observed program behavior.
- **Output:** a diagnosis, correction, or explanation of the bug.
- **Out of scope:** hiding errors without understanding their cause.
