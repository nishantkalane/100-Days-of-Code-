# Day 6: Functions

## Topic learned

Defining functions, parameters, arguments, return values, and combining functions with loops.

## Why it matters

Functions give a program named, reusable pieces that are easier to read, test, and change.

## Small example

```python
def square(number):
    return number * number


print(square(5))
```

## Question to revisit

Which values should a function receive, and which result should it return?
