# Day 4: Collections and Randomness

## Topic learned

Lists, indexes, list errors, importing modules, and random selection.

## Why it matters

Collections store related values, and randomness allows programs to create varied games and outcomes.

## Small example

```python
choices = ["rock", "paper", "scissors"]
print(choices[0])
```

## Question to revisit

## Project: Rock Paper Scissors

- **Problem:** play one round against the computer.
- **Features:** accept a choice, choose a random computer move, compare moves, display the result.
- **Inputs:** a number representing rock, paper, or scissors.
- **Output:** both choices and the winner.
- **Out of scope:** accounts, networking, and a persistent leaderboard.
