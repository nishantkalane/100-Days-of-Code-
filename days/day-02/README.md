# Day 2: Data Types and Arithmetic

## Topic learned

Data types, type conversion, arithmetic operators, number manipulation, and formatted numeric output.

## Why it matters

Programs must know whether they are working with text, whole numbers, or decimal values before performing operations.

## Small example

```python
price = float("4.50")
quantity = int("2")
print(price * quantity)
```

## Question to revisit

When should input be converted, and what happens if conversion receives invalid text?
