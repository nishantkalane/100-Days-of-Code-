# Day 1: Python Foundations

## Topic learned

Variables, strings, input, output, string manipulation, and naming values clearly.

## Why it matters

These are the basic building blocks of every Python program. They let a program receive information, remember it, and communicate a result.

## Small example

```python
name = input("Name: ")
print(f"Hello, {name}!")
```
