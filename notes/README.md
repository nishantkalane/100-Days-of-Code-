# Learning Notes

These notes summarize the Python ideas practiced each day. They are personal reminders, not copies of the course lessons.

When finishing a day, add three things:

1. What I understood.
2. What confused me or caused a bug.
3. What I would build or improve next.

The project README belongs beside the project code. Broader concepts and reflections belong here.

## Required sections for future notes

Each new `day-XX.md` should include:

- **Learned:** the main Python ideas understood that day.
- **Topics in plain language:** necessary technical terms explained simply.
- **Technical Python practice:** the syntax or behavior practiced.
- **Small example:** a short example that can be understood independently.
- **Practice record:** the project or exercise completed.
- **Next review:** one specific thing to revisit.

Use the [daily workflow](../DAILY_CHECKLIST.md) for the full process.
